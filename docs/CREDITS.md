# Credits

Leonida V downloads every mod from its author's own page or release and never bundles, re-hosts or changes the
authors' files. All rights belong to them. Thank you to every author below.

Licences: what the author publishes (a GitHub `LICENSE`, read 2026-11-25, or a line on the mod's page). Most
gta5-mods and Nexus pages state none, so those mods are **all rights reserved**: Leonida only links to them, and
a Leonida release never carries their files (`redistribution` in mods.json stays off).
